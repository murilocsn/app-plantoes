# Manual do usuario

Status: PARCIALMENTE IMPLEMENTADA

## Acesso

1. Entrar no app.
2. Fazer login com e-mail/senha conforme Supabase Auth configurado.
3. Acessar o painel principal.

## Painel

O painel apresenta uma visao geral da rotina profissional, com dados vindos da API.

## Plantoes

O usuario pode criar, editar, listar e remover plantoes. Cada plantao pode ter data, horario, local, valor, status e marcador visual.

## Locais

O usuario pode cadastrar locais de trabalho e dados relacionados ao pagamento.

## Financeiro

O usuario pode acompanhar recebiveis e despesas. Recebiveis podem ser marcados como pagos.

## Espacos

Funcionalidade parcialmente implementada para organizacao compartilhada.

## Relatorios

Ha exportacao CSV por rota da API.

## Lembretes

Lembretes push estao parcialmente implementados e dependem de permissao do navegador, VAPID e cron configurado.
