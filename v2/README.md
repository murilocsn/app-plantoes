# FinancPlantões 2.0

Nova base visual e arquitetural do FinancPlantões, construída sobre o projeto existente.

## Estrutura

- `index.html` — shell visual do dashboard 2.0
- `styles.css` — design system responsivo com tema claro/escuro
- `app.js` — persistência do tema e navegação do shell

## Direção do produto

- Plantões e recorrências
- Locais de trabalho e regras de pagamento
- Contas a receber e previsão de recebimentos
- Despesas pessoais
- Espaços compartilhados: residência, clínica, viagem, evento e equipe
- Membros, convites e papéis de acesso
- Despesas compartilhadas, divisões e acertos

A integração com autenticação, dados reais e router será feita incrementalmente após a validação do novo modelo de dados.
